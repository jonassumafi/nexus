    Design tokens introduced on this page

    Mission type accents are new. Each type badge and picker card takes its color from one custom property, and the tinted background and border are derived from it with color-mix, so a new type from PlatformConfig.mission_types only needs one color. Stepper states reuse existing blue and lime. Everything else comes from the companion spec.

    Combat--ty-combat
    Trade--ty-trade
    Exploration--ty-explore
    Salvage--ty-salvage
    Escort--ty-escort
    Mining--ty-mining
    Medical--ty-medical
    Patrol--ty-patrol

    Components. Stepper: 28px raised discs, current step sits 2px lower in blue, finished steps turn lime and can be clicked to go back. Progress bar: 3px, blue gradient. Selectable cards: raised, selected adds a 1px blue outline and a lime check disc. Footer: Cancel (ghost), Back (standard), Next (lime, becomes Create Mission on step 6). Validation text appears in the footer in red and the offending field gets a red border.

    Field mapping. name, mission_type, primary_ship, supporting_ships, objectives, mission_time, queue_expires_at, is_public. Status on create is WAITING FOR CREW (schema default). Assumed rules: name must be unique (schema), objectives need at least 10 words, ships per mission is max_ships_per_mission (3) counting the primary ship, queue expiry must fall before the mission time.
