Direction C, Flight Strip

This direction treats the companion as an air traffic control board instead of a device. Every item is a flat strip: a colored tab, hairline-divided columns and large tabular numerals. The frequency is a split-flap display, so retuning has a physical beat without any glow. Surfaces are matte color blocks with no gradients or under-edges, which keeps text crisp and the window readable at low opacity over a bright game scene. It departs from the current look by dropping bevels in favor of grid, type and color. Scaling: Full is an ops board with counters, a strips table and a detail panel. Companion is a vertical board with an active strip, tabbed strips, a flap row and chat. Radio is a single strip with flap frequency, speaker callsign and key tile; its drawer holds mode, transparency, mute and peers.
