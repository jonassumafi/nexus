# Discord Bot Reference (Mission Control)
Original source files for the Hopewell Continuum
Mission Control Discord bot. Nexus 1.0 is the
web-based successor to this system.

These files are the source of truth for:
- RP system logic → bot/cogs/rp_handler.py
- Mission lifecycle → bot/cogs/mission/mission_commands.py
- Crew slot management → bot/cogs/ship/crew_commands.py
- Onboarding flow → bot/utils/views.py, bot/utils/modals.py
- Rank thresholds → bot/utils/views.py, bot/core/constant.py
- Ship management → bot/cogs/ship/ship_commands.py
- Embed styling → bot/utils/embeds.py
- Data schemas → bot/core/models/database_models.py

Do not modify. Reference only.
