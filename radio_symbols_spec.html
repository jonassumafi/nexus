Radio Symbols, Spec

Spec and mockup in one file for the 20 radio profiles in the radio type picker. Each profile gets one single color line symbol that takes its color from the skin accent, so it follows all nine skins. Symbols appear only in the picker. They are not used on the strip chips. Pick a skin, then click any radio to see the picker update.

Rules

  1. Where. Only in the radio type picker. Each row gets a 34 px tile on its left holding a 20 px symbol, and the Current rig header shows the symbol at 22 px before the band tag. Nowhere else, including the strip chips and the roster.
  2. Drawing. 24 unit viewBox, 1.7 stroke, round caps and joins, no fills except small dots, all in currentColor.
  3. Color. The symbol uses acc2. The tile uses an inset well (bg0 mixed 80 percent with black) and a rim0 border. The selected row uses an acc2 border and a 9 percent acc2 tint. No hardcoded colors.
  4. Unique. One symbol per profile, even when names share a word (the two Patrols differ).
  5. No padlock. Reserved for the locked indicator on the radios.
  6. Static. No animation and no hover effect on the symbols.
  7. Fallback. A profile with no symbol shows the dashed circle at the end of the sheet. Match symbols by profile id, and never fail if one is missing.
